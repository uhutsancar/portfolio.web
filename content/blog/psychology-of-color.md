Color in interface design is not only decoration.

It can establish hierarchy, guide attention, communicate
status, reinforce a brand, and help users understand what
actions are available.

## Color and visual hierarchy

Strong colors naturally attract attention.

For this reason, accent colors should be reserved for important
actions, selected elements, and meaningful interface states.

When every element uses a strong color, the hierarchy becomes
unclear because nothing appears more important than anything
else.

## Functional colors

A consistent product should separate brand colors from
functional colors.

Common functional roles include:

- Primary
- Success
- Warning
- Error
- Information
- Neutral

These roles make interface states easier to understand and
maintain across different screens.

## Accessibility

Color should never be the only method used to communicate
important information.

Error messages should combine color with text or an icon.
Selected elements should include a visible structural change.
Text and background combinations should also maintain
sufficient contrast.

## Context matters

Color meanings can change depending on culture, audience,
product type, and surrounding colors.

A successful palette should therefore be tested with real
content and real users rather than selected only because it
looks attractive in a design file.
